## Hi, I'm Edgar David Mariano Ruiz

Systems engineer from Guerrero, Mexico. I build Python backends and applied AI, mostly retrieval-augmented generation (RAG) systems that answer questions from official documents and cite the exact article each answer comes from, using open-source models that run on local hardware.

MSc student in Engineering for Innovation and Technological Development at Universidad Autónoma de Guerrero (2025–2027). **Open to remote roles as a backend or Python developer.**

### Featured projects

**[rag-legal-guerrero](https://github.com/DavidMariano300/rag-legal-guerrero)** · Legal Q&A for lawyers in Guerrero, Mexico. Every answer quotes the article it relies on, and an answer whose quote is not in the retrieved text is replaced by a refusal. FastAPI, Qdrant, PostgreSQL, Ollama, React + TypeScript, Docker Compose, 88 tests in CI. [Live demo](https://amate-demo.northcentralus.cloudapp.azure.com) (CPU only, about two minutes per answer).

**[grounded-rag-es](https://github.com/DavidMariano300/grounded-rag-es)** · Source-cited RAG toolkit for Spanish-language regulations: page-level OCR, legal hierarchy reconstruction, a deterministic fidelity gate for LLM text cleanup, and 15 retrieval methods compared on PostgreSQL + pgvector. Tested on 105 documents and 6,291 fragments.

**[rezago-ems-mexico](https://github.com/DavidMariano300/rezago-ems-mexico)** · Predictive model built only from open data (INEGI, SEP, CONEVAL) for 2,469 municipalities. Out-of-sample R² of 0.627 with whole states held out, against 0.112 for the baseline.

**[prompt-debil-vs-fuerte](https://github.com/DavidMariano300/prompt-debil-vs-fuerte)** · Controlled experiment: the same web app generated from a weak and a strong prompt, and what changes in logging, error handling and security.
